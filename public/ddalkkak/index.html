QUESTIONS

먼저 물어보시는 것

AI로 쓴 글이라고 네이버가 막지는 않나요?

네이버는 AI를 썼다는 것만으로 판단하지 않는다고 공식 블로그에 밝혀 두었습니다. 조심할 것은 허락 없는 자동 로그인과 자동 게시예요. 그래서 기본은 사장님이 직접 올리는 방식(사진 보내기와 글 복사)이고, 자동 올리기는 약관 안내를 읽고 동의한 뒤 하루 3편까지 되고, 앞 글과 40분이 안 지났으면 한 번 더 묻습니다. 발행 단추만 직접 누르고 싶으면 임시저장으로 두면 됩니다.

네이버 비밀번호를 맡겨야 하나요?

직접 올리기는 비밀번호가 필요 없습니다. 자동 올리기를 쓸 때만 연결하고, 비밀번호는 암호화해서 보관합니다. 설정에서 연결을 끊으면 비밀번호와 로그인 기록은 바로 지워져요.

사진에 없는 내용도 써 주나요?

안 씁니다. 가격, 작업 시간, 고객 반응처럼 사진과 메모에 없는 내용은 빼요. 손님 상호도 넣지 않습니다. 더 넣고 싶은 내용은 한 줄 메모로 적으면 반영됩니다.

유튜브도 자동으로 올라가나요?

구글 계정을 연결하면 올라갑니다. 다만 구글이 자동 로그인을 막을 때가 있어요. 그때는 영상을 받아 유튜브 앱으로 올리시면 되고, 영상은 언제든 받을 수 있습니다.

폰으로만 써도 되나요?

네. 폰 브라우저에서 열고 홈 화면에 추가하면 앱처럼 씁니다. 사진을 고른 뒤 화면을 꺼도 글은 계속 써지고, 다시 열면 이어서 보여 줍니다.
