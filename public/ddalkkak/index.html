QUESTIONS

먼저 물어보시는 것

네이버 비밀번호를 맡겨도 되나요?

비밀번호는 암호화해서 보관하고 블로그에 올릴 때 로그인하는 데만 씁니다. 설정에서 연결을 끊으면 비밀번호와 로그인 기록은 바로 지워져요. 보안문자나 휴대폰 승인이 나오면 화면이 떠서 사장님이 직접 누릅니다.

네이버에서 막히지는 않나요?

네이버는 블로그 글쓰기용 공식 연결을 2020년에 닫았습니다. 그래서 사람이 쓰는 글쓰기 화면에 대신 써 넣는 방식이에요. 하루 수십 편을 몰아 올리면 제한될 수 있어 하루 최대 10편으로 묶어 두었습니다.

사진에 없는 내용도 써 주나요?

안 씁니다. 가격, 작업 시간, 고객 반응처럼 사진과 메모에 없는 내용은 빼요. 손님 상호도 넣지 않습니다. 더 넣고 싶은 내용은 한 줄 메모로 적으면 반영됩니다.

유튜브도 자동으로 올라가나요?

구글 계정을 연결하면 올라갑니다. 다만 구글이 자동 로그인을 막을 때가 있어요. 그때는 영상을 받아 유튜브 앱으로 올리시면 되고, 영상은 언제든 받을 수 있습니다.

폰으로만 써도 되나요?

네. 폰 브라우저에서 열고 홈 화면에 추가하면 앱처럼 씁니다. 사진을 고른 뒤 화면을 꺼도 글은 계속 써지고, 다시 열면 이어서 보여 줍니다.
